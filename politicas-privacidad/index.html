RADIO MÓVIL / PRIVACIDAD

Política de privacidad

Información sobre el tratamiento de datos al usar Radio Móvil, aplicación para consultar y gestionar autorizaciones de propuestas de pago del SET.

Última actualización: 17 de noviembre de 2026

1. Responsable

El responsable del tratamiento de los datos personales utilizados por Radio Móvil es 2026 TI Soluciones Globales en Tesorerías Corporativas S. de R.L. de C.V., con domicilio en Av. Insurgentes Sur núm. 307, departamento 404, colonia Hipódromo Condesa, alcaldía Cuauhtémoc, C. P. 06170, Ciudad de México, México. Para consultas sobre privacidad, escribe a bmondragon@globalset.mx.

2. Datos tratados

Para autenticar a usuarios autorizados, mostrar propuestas de pago y registrar sus decisiones, el servicio trata los siguientes datos:

  • Identificación de usuario y facultades asignadas en el SET.
  • Credenciales proporcionadas para iniciar sesión.
  • Información de propuestas, detalles, niveles y estados de autorización.
  • Decisiones de autorización o rechazo y, cuando corresponda, motivo de rechazo.

3. Uso de los datos

Los datos se utilizan para permitir el acceso a usuarios con facultades, consultar propuestas, registrar decisiones y sincronizar los cambios con el SET. La aplicación se comunica con una API intermediaria para realizar estas funciones.

Según la información proporcionada por el responsable, Radio Móvil no comparte datos personales con terceros.

4. Seguridad y conservación

El acceso a las funciones de la aplicación depende de las credenciales y facultades del SET. Radio Móvil no almacena los datos localmente en la aplicación: los consulta mediante una API para presentar la información y enviar las decisiones de autorización. Para conocer la conservación de datos en los sistemas que proporcionan el servicio, escribe a bmondragon@globalset.mx.

5. Derechos y contacto

Para solicitar acceso, rectificación, cancelación u oposición respecto de sus datos personales, o para plantear dudas sobre esta política, las personas usuarias pueden escribir a bmondragon@globalset.mx. En la solicitud deben identificar los datos y el derecho que desean ejercer, así como proporcionar un medio para recibir respuesta.

6. Cambios a esta política

Las modificaciones se publicarán en esta misma página, con la fecha de actualización correspondiente.
