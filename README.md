# Radio Móvil · Política de privacidad

Sitio estático para GitHub Pages. La raíz redirige a `politicas-privacidad/` y ambas páginas usan el icono de `assets/`.

## Publicación

1. Sube estos archivos a la raíz del repositorio de GitHub.
2. En **Settings → Pages**, elige **Deploy from a branch**, la rama que publicaste y la carpeta **/(root)**.
3. Abre la URL de GitHub Pages del repositorio. La raíz redirigirá a la política.

Antes de publicar, revisa que las categorías de datos y el funcionamiento de la aplicación y la API descritos en la política correspondan a la operación real del servicio. La aplicación no almacena datos localmente; para conocer la conservación en los sistemas conectados, la política ofrece el correo del responsable.
